# Telegram Channel Button Bot (PHP) — v1.8

ربات تلگرامی انتشار پست **متنی یا عکس‌دار با چند دکمه لینک‌دار** در کانال، بدون برچسب فوروارد یا «via». سازگار با هاست اشتراکی و cPanel.

> **وضعیت:** این مخزن شامل سورس نسخه 1.8 است. تست نحوی و سناریوهای آفلاین انجام شده‌اند؛ عملکرد نهایی وابسته به دسترسی‌ها و محدودیت‌های Telegram Bot API است.

## قابلیت‌ها

- ساخت پست متنی یا عکس با کپشن و چندین دکمه لینک‌دار
- تنظیم عنوان، لینک و **رنگ مجزا** (سبز، آبی، قرمز یا پیش‌فرض) برای هر دکمه؛ نمایش رنگ به نسخه تلگرام بستگی دارد
- تغییر ترتیب و قرارگیری دکمه‌ها در یک یا دو ستون
- پیش‌نمایش و تأیید قبل از انتشار مستقیم در کانال
- استفاده عمومی با تنظیمات و پیش‌نویس مجزای هر کاربر
- کنترل مجوز کاربر و ربات برای انتشار در کانال
- آرشیو پست‌های منتشرشده، ویرایش دکمه‌های همان پست، و کپی بدون فوروارد در کانال دیگری
- پشتیبانی از قالب‌بندی متن و تلاش برای حفظ custom emoji (محدودیت‌های تلگرام ممکن است باعث تبدیل به ایموجی معمولی شوند)
- نصب بدون دیتابیس و بدون اجرای پردازش دائمی، با Webhook

## پیش‌نیازها

- PHP 8.1 یا جدیدتر با دسترسی HTTPS (و ترجیحاً افزونه cURL)
- هاست دارای HTTPS معتبر و پوشه `storage` قابل نوشتن
- توکن ربات از [@BotFather](https://t.me/BotFather)
- مدیر کانال بودن ربات با مجوز `Post Messages`؛ خود کاربر هم باید در آن کانال دسترسی لازم را داشته باشد

## نصب (هاست اشتراکی / cPanel)

1. محتوای مخزن را در پوشه‌ای مانند `public_html/telegram-button/` بارگذاری کن.
2. از فایل `config.example.php` یک کپی با نام **`config.php`** بساز.
3. در فایل `config.php` فقط توکن ربات و شناسه **عددی** مالک را درج کن:

   ```php
   return [
       'bot_token'     => 'BOT_TOKEN_FROM_BOTFATHER',
       'admin_user_id' => 123456789,
   ];
   ```

4. پوشه `storage` باید قابل نوشتن برای PHP باشد؛ دسترسی‌های امن هاست را حفظ کن (از `777` استفاده نکن).
5. توکن را به دو قسمت `123456789:LONG_SECRET` تقسیم کن؛ قسمت پس از دونقطه (`LONG_SECRET`) به‌عنوان `secret_token` وب‌هوک استفاده می‌شود.
6. URL زیر را با اطلاعات **خودت و به‌شکل خصوصی** جایگزین و در مرورگر باز کن:

   ```text
   https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https%3A%2F%2Fexample.com%2Ftelegram-button%2Fwebhook.php&secret_token=<LONG_SECRET>
   ```

7. پاسخ `Webhook was set` را بررسی کن، سپس داخل چت خصوصی ربات دستور `/start` را بزن.

**نکته:** باز کردن مستقیم `webhook.php` در مرورگر با متد `GET` ممکن است پاسخ `405 Method Not Allowed` بدهد؛ این رفتار برای وب‌هوک طبیعی است. برای عیب‌یابی از `getWebhookInfo` استفاده کن.

## استفاده

- **ساخت متن دکمه‌دار:** متن/عکس → عنوان دکمه → لینک دکمه → افزودن دکمه‌های دیگر و چیدمان → کانال مقصد → پیش‌نمایش و تأیید.
- **تنظیمات بات → مدیریت پست‌های منتشرشده:** پست را با شناسه پیام مانند `#159` انتخاب کن، عنوان/لینک/رنگ و ترتیب دکمه‌ها را تغییر بده یا همان پست را در کانال دیگری منتشر کن.
- برای پست‌های خیلی قدیمی که آرشیو دکمه‌هایشان موجود نیست، باید دکمه‌ها را یک‌بار از نو تعریف کنی.

## امنیت و حریم خصوصی

- **هرگز `config.php` یا `storage/state*.php` را به GitHub نفرست.** این مسیرها در `.gitignore` قرار دارند؛ قبل از Push حتماً فایل‌های Stage شده را هم بررسی کن.
- کلید باتی که در اسکرین‌شات، چت یا مخزن عمومی دیده شده باید فوراً از BotFather **Revoke** شود؛ حذف از گیت‌هاب به‌تنهایی آن را امن نمی‌کند.
- وب‌هوک درخواست‌های دارای هدر امنیتی اشتباه را رد می‌کند؛ هنگام ست کردن وب‌هوک حتماً `secret_token` معتبر وارد کن.
- انتشار عمومی کد به معنی دریافت مجوز قانونی استفاده مجدد از آن توسط دیگران نیست. این مخزن در حال حاضر **فایل مجوز (LICENSE) ندارد**؛ پیش از عرضه متن‌باز، مجوز مناسب را تعیین کن.
